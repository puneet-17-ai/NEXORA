# Nexora — Responsive Landing Page

A responsive landing page created for the **YuvalIntern Junior Frontend Developer Internship — Week 1 Task**.

## Objective
Transform a standard landing-page wireframe concept into a live, responsive HTML/CSS/JavaScript implementation.

## Features
- Semantic HTML5 structure
- Responsive desktop, tablet and mobile layouts
- CSS Grid and Flexbox
- Mobile navigation menu with JavaScript
- Smooth scrolling
- Scroll-based reveal animations
- Accessible navigation labels
- Reduced-motion support
- Clean component-like CSS organization
- No external frameworks or dependencies

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure
```text
nexora-landing-page/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
```

## How to Run
Open `index.html` in a modern browser. No build step is required.
